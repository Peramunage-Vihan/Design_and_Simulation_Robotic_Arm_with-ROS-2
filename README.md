# 4-Link Robotic Arm Simulation in ROS 2

[cite_start]This repository contains the full design and simulation files for a 4-link robotic arm[cite: 32]. [cite_start]The project covers the complete workflow from 3D modeling in SolidWorks to kinematic simulation in Gazebo and visualization in RViz[cite: 33, 35].

## 📋 Project Overview

[cite_start]The primary goal of this project was to design a robotic arm from concept and validate its design and control logic using the ROS 2 simulation ecosystem[cite: 32, 35].

This repository includes:
* [cite_start]**SolidWorks Models:** The original 3D CAD files for all links and joints of the arm[cite: 33].
* [cite_start]**URDF File:** The Unified Robot Description Format (URDF) file, which integrates the 3D model into the ROS 2 environment[cite: 34].
* [cite_start]**Gazebo Simulation:** Launch files and worlds to simulate the arm's kinematics in the Gazebo simulator[cite: 35].
* [cite_start]**RViz Visualization:** Configuration files to visualize the arm's model, joints, and sensor data in RViz[cite: 35].

## 🛠️ Tools Used

* **CAD:** SolidWorks
* **Simulation:** ROS 2, Gazebo
* **Visualization:** RViz
* **Integration:** URDF
