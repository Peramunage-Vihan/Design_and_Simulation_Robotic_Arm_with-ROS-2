# 4-Link Robotic Arm Simulation in ROS 2

This repository contains the full design and simulation files for a 4-link robotic arm.The project covers the complete workflow from 3D modeling in SolidWorks to kinematic simulation in Gazebo and visualization in RViz.

## 📋 Project Overview

The primary goal of this project was to design a robotic arm from concept and validate its design and control logic using the ROS 2 simulation ecosystem.

This repository includes:
* **SolidWorks Models:** The original 3D CAD files for all links and joints of the arm.
* **URDF File:** The Unified Robot Description Format (URDF) file, which integrates the 3D model into the ROS 2 environment.
* **Gazebo Simulation:** Launch files and worlds to simulate the arm's kinematics in the Gazebo simulator.
* **RViz Visualization:** Configuration files to visualize the arm's model, joints, and sensor data in RViz.

## 🛠️ Tools Used

* **CAD:** SolidWorks
* **Simulation:** ROS 2, Gazebo
* **Visualization:** RViz
* **Integration:** URDF
